# Every escaping-captured container gets its declaration-site cell

ADR-16595 slice 1 (#16596). An `@`/`%` lexical that an escaping closure captures now always gets a shared `ContainerRef` cell at its declaration. Before this change, the ADR-0055 vouch exempted a container the owning frame never writes. That vouch proves single-thread name resolution only. A vouched `@log` captured by a `tap` or `.then` callback, which later runs on another thread, had no cell, so that thread could reach it only through the name-keyed `shared_vars` lane. The set is renamed `needs_cell_captured_containers`. A celled array is now also named correctly in an element type-check failure from `ASSIGN-POS` (`Type check failed for an element of @t`), which had read `$` once the binding sat in a cell.
