# A block's module-merge grant lives in the import region's own env tier

The package grant a block's `use` or `need` makes (`M::sub` resolves inside the block) used to be an env key that the scope recorded in `imported_env_keys` and `shadowed_env_values` and that `restore_import_env_keys` removed again on exit. `OpCode::ImportScope` now runs its body over an env tier of its own and merges every write back except the grant, so the grant ends with the region on every exit path without a key list or a restore. The scope keeps only a `merged_modules` set (for `hide_unit_names_from_frame`, `MY::` and the replay record). This is the grant slice of ADR-14140 (Proposed); the other import kinds still use the key list. Per executed region the cost is unchanged within noise (callgrind, debug build: 251.4K Ir per `{ use M }` before, 249.8K after).
