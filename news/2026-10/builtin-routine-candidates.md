# Built-in routines expose their candidates

`&say.candidates`, `Str.^can("Int")[0].candidates` and the other built-in
routines now return one code object per candidate Rakudo declares, instead of an
empty list. Each carries its signature, its `multi` flag and its `SETTING::`
declaration site (`.file` / `.line`), and `.cando(\(...))` filters them by
argument capture. The data is a committed snapshot of Rakudo's core candidates
(`src/builtins/rakudo_candidates.txt`, regenerated by
`scripts/gen-rakudo-candidates.raku`), the same approach as the method-table
oracle. This is what the `sourcery` distribution needs to answer "where is this
built-in defined" (#12472).

Invoking a candidate code object directly is not supported yet; it throws.
