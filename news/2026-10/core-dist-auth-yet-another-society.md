# The vendored core dist's `auth` is `Yet Another Society`

`modules/Rakudo-Core/META6.json`, the dist holding the vendored `Test`, `NativeCall`, `Pod::To::Text`
and `Telemetry`, carried an invented authority, `github:rakudo`. Those files are Rakudo's core files
(`Test.rakumod` carries `Copyright (C) 2007 - 2026 Yet Another Society`), so
`CompUnit::RepositoryRegistry.repository-for-name("core").installed.head.meta<auth>` now answers
`Yet Another Society`, as `raku` does. The dist's `name` stays `Rakudo-Core`: renaming it to `rakudo`
would claim the compiler is Rakudo, which ADR-0104 rules out (`$*RAKU.compiler.name` stays mutsu).
`Rakudo::CORE::META` 0.0.12 filters the core repository by `auth`, so its `t/01-basic.rakutest` is
13/13 (it was 12/13). `site/content/batteries.json` is regenerated by
`scripts/gen-batteries-manifest.py`, which also brings it up to date with the bundle (#14116).
