# An augmented multi is ranked with the built-in candidates of the method

Rakudo ranks an `augment`ed `multi method` of a core type together with the built-in candidates
of the method it names, and does not add a `multi` declared on an ancestor to the dispatcher of a
more derived core class that declares the method itself. mutsu ran every program-declared
candidate ahead of the built-in method. `augment class Any { multi method first(Callable $c) {...} }`
no longer takes `(1, 2, 3).first(* > 1)` from the built-in `Callable:D` candidate, and
`augment class Any { multi method head(Int $x) }` no longer reaches `List.head`
(`rakudo_method_candidates.txt` holds Rakudo's candidate signatures, generated by
`scripts/gen-rakudo-method-candidates.raku`; each is turned into a body-less method and ranked by
the walk that ranks the program's own candidates). Cases that Rakudo reports as ambiguous still
pick the program's candidate (#12751).
