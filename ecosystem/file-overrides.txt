# ecosystem/file-overrides.txt
#
# Per-file run conditions for known-slow test files, so the sweep stops
# flapping on them. Read by scripts/ecosystem-sweep.py; only a listed file is
# affected, and the global `--timeout` stays the cap for everything else.
#
# Format: <Dist::Name> <test/path> <option>[ <option>...] -- <reason, with an issue link>
#
#   timeout=<seconds>  a longer per-file budget for this file, on both sides
#                      (an override never shortens the default; a timed-out
#                      first attempt still gets the usual doubled retry)
#   alone              run this file while no other sweep job runs an
#                      interpreter, for a suite whose own timing assertion
#                      fails on a loaded runner
#
# Every entry is a workaround with an end date: once the issue it cites is
# tuned -- the file passes comfortably under the normal cap and load -- delete
# its line. A line whose first non-blank character is `#`, and every blank
# line, is ignored. Keep sorted by name.
