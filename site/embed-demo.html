Embed mutsu in a web page

The GitHub Pages site uses the published @tokuhirom/mutsu npm package. The runnable component below is the same Web Component that applications install.

Use it directly from a CDN

For a static page, add the component and load its module from jsDelivr. Pin a released version in production so an existing page does not change unexpectedly.

<mutsu-code autorun>
  <script type="text/raku">
say "Hello from mutsu!";
  </script>
</mutsu-code>

<script type="module"
  src="https://cdn.jsdelivr.net/npm/@tokuhirom/mutsu@0.23.0/embed.js">
</script>

Install it with npm

Bundled applications can import the component from the package. Its WebAssembly binary is included; users do not need Rust or wasm-pack.

npm install @tokuhirom/mutsu
import '@tokuhirom/mutsu/element';

Use the JavaScript API

Use the lower-level API when the application provides its own editor or output UI.

import init, { evaluate, Repl } from '@tokuhirom/mutsu';

await init();
console.log(evaluate('say "Hello"'));

const repl = new Repl();
console.log(JSON.parse(repl.evalLine('my $answer = 40')));
console.log(JSON.parse(repl.evalLine('$answer + 2')));

The component also supports readonly and session attributes and emits a mutsu-run event. See the complete embedding reference for those options and the browser limitations.
